## 发现问题（已登记 feature_list）

- **p32-13（P1，本轮新发现，确定性复现×2）**：交还后完成任一章节 mutation（实测 restore 成功）→ 工作权泄漏：`busy=true` 且 `task=None`，此后所有编辑/回退/继续协作被 409 互锁，**只能重启解除**。即体验报告 #6"编辑与批准互锁需重启"的根因复现。可疑点已注记（finishCollaborative 的 endWork 非 finally 顺序、嵌套 workId）。
- **p32-11**：全书质量评价结果不持久化（无 GET），切 tab/刷新即"尚未评价"（报告 #7 复现）。
- **p32-12**：活动期/泄漏期 409 均显示"章节已被更新，请重新确认"，误导重试（应区分所有权占用）。
- 体验类：章节卡 HTTP 缓存导致普通 F5 读旧数据（硬刷新才更新）；截图 CDP 超时（与报告环境一致）。
