# Spec: E2E 回放被人审屏障暂停（1 章后停写）

> 2026-10-09 从 NCS-185 验证过程中的 A/B 证据登记。补登记说明：feature_list 原将诊断描述误填在 spec 字段，本文件为对应规格化落盘。

## 背景与动机

NCS-185 合并前后运行 `./scripts/e2e.sh`（replay 模式）均出现同一签名失败：写作 1 章后流程在章节评审屏障处暂停，无法完成 3 章验收目标。A/B 对照：main(1ddc4d5) 与 NCS-185 分支同签名失败，排除该 feature 引入。`data/e2e/events.jsonl` 诊断显示质量阻断信号：人审屏障（REVIEW_BARRIER_RAISED）1 次、写作暂停 1 次。

## 目标

- 查明屏障触发根因：近期 main 的评审策略变化（NCS-178 check 预算 / 评审屏障相关）还是 e2e 场景配置缺少自动放行。
- e2e 回放恢复确定性 3 章验收能力。

## 非目标

- 不改变生产（真实写作）路径的人审屏障语义。

## 验收标准

- [ ] `./scripts/e2e.sh` 回放完成 3 章且 e2e-report.json 无未决屏障；或屏障为断言内预期行为（e2e.sh 明确断言屏障语义并记录）

## 影响面

- **涉及模块**: scripts/e2e.sh、service/（评审屏障策略）
- **涉及 prompt 模板**: 无
- **数据库 schema 变更**: 无
- **质量基线影响**: 无（回放流程修复，不改生成内容）

## Feature 拆分

| id | name | 依赖 | acceptance | verify_cmd |
|----|------|------|------------|------------|
| NCS-186 | E2E 回放被人审屏障暂停 | [] | e2e 回放完成 3 章且报告无未决屏障，或屏障为断言内预期行为 | `./scripts/e2e.sh` |

## 风险与备选方案

- 若屏障源于既有 replay 语料本身质量问题（评分低触发 NEEDS_MANUAL_REVIEW），考虑 e2e 场景放宽该章评审阈值而非全局改策略。
