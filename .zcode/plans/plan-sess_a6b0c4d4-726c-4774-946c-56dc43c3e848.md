# Phase 6: 写作配置框架 — 预设模板 + 对话调优 + 反馈闭环

## 设计理念

将写作质量从"代码硬编码"提升为"**可打包、可对话调优、可复用的配置框架**"：

```
WritingPreset (可打包的配置模板)
  ├── preferences: WritingPreferences 覆盖值
  ├── styleSeed: StyleProfile 种子值
  ├── genreHint: GenreProfile 提示
  └── 可保存/加载/分享

WritingPreferencesAgent (对话调优)
  ├── 作者："让对话更有古风"  → 调整 styleSeed + dialogueDifferentiation
  ├── 作者："减少打斗，增加推理" → 调整 climaxRotation + 引用素材
  └── 所有参数可运行时动态修改

ContextFeedbackCollector (反馈闭环)
  ├── 读取所有 ContinuityIssue（风格漂移/剧情停滞/伏笔未回收）
  ├── 按优先级注入 WritingContext.feedbackSection
  └── 下章写作时 LLM 看到历史问题，避免重犯
```

---

## p6-1: WritingPreset — 预设模板系统

### 问题
创建项目时只有 `title/concept/tags/mode`，WritingPreferences 延迟初始化、StyleProfile 无种子、GenreProfile 无法覆盖。无法打包和复用配置。

### 方案

**新增 `WritingPreset` 领域对象** — 可序列化的完整配置包：

```java
public class WritingPreset {
    String name;           // "硬核修仙"、"古风言情"、"悬疑推理"
    String description;
    GenreProfile genreHint;           // 题材提示（覆盖自动检测）
    Map<String,Object> preferences;   // WritingPreferences 覆盖值
    String styleTone;                 // StyleProfile 种子
    String styleVoice;
    String styleDosAndDonts;
}
```

**内置预设（JSON 文件）：**
- `classpath:presets/cultivation.json` — 硬核修仙：高爽点密度、境界节奏、战斗为主
- `classpath:presets/mystery.json` — 悬疑推理：线索驱动、慢节奏、逻辑严密
- `classpath:presets/romance.json` — 古风言情：高对话密度、情感节拍、诗词引用
- `classpath:presets/thriller.json` — 惊悚悬疑：高压节奏、危机递进
- `classpath:presets/historical.json` — 历史权谋：权谋对话、史实引用、低战斗
- `classpath:presets/general.json` — 通用平衡（默认）

**创建项目时指定预设：**
```
POST /api/projects
{
  "title": "九转星辰诀",
  "concept": "...",
  "tags": "玄幻,修仙",
  "preset": "cultivation"    ← 新增字段
}
```

**生命周期改动：**
- `ProjectService.create()` 接受 preset 参数
- 如果有 preset：立即初始化 WritingPreferences + StyleProfile 种子 + GenreProfile
- 如果无 preset：走原有延迟初始化逻辑

**API：**
- `GET /api/presets` — 列出所有可用预设
- `GET /api/presets/{name}` — 查看预设详情
- `POST /api/presets` — 保存自定义预设（当前项目配置打包）
- `POST /api/projects` 新增 `preset` 字段

### 修改文件

| 文件 | 改动 |
|------|------|
| `domain/WritingPreset.java` | **新建**领域对象 |
| `service/PresetRegistry.java` | **新建**。加载内置预设 + 管理自定义预设 |
| `resources/presets/*.json` | **新建** 6 个内置预设文件 |
| `web/dto/CreateProjectRequest.java` | +`preset` 字段 |
| `orchestrator/ProjectService.java` | create() 接受 preset，初始化完整配置 |
| `web/ProjectController.java` | POST 接受 preset 字段 |
| `web/PresetController.java` | **新建** REST API |

## p6-2: ContextFeedbackCollector — 反馈闭环中枢

### 问题
每章的 ContinuityIssue（风格漂移/剧情停滞/伏笔问题）都是 fire-and-forget，ContextAssembler 从不读取。

### 方案
**新增 `WritingContext.feedbackSection` + `ContextAssembler.buildFeedbackSection()`**

统一收集所有反馈源，按优先级组装：

```
【历史反馈（以下问题在近期章节中被发现，本章应避免重犯）】
■ [HIGH] 人物：叶辰的名字不能写成"叶尘"
■ [MEDIUM] 风格：第5章文风转向史诗，本章需回归写实
■ [MEDIUM] 剧情节奏：连续2章低张力，需提升冲突
```

**WritingPreferences 控制：**
- `enableFeedbackInjection` (默认 true)
- `feedbackWindow` (默认 10 章)

### 修改文件

| 文件 | 改动 |
|------|------|
| `WritingPreferences.java` | +`enableFeedbackInjection` +`feedbackWindow` |
| `WritingContext.java` | +`feedbackSection` 字段 + toSystemPrompt 渲染 |
| `ContextAssembler.java` | +`buildFeedbackSection()` 查询未解决 ContinuityIssue |
| `preferences-chat.st` | 文档化新参数 |
| `chapter-writing.st` | +`{{#if feedbackSection}}` 条件块 |

## p6-3: CharacterVoiceEnhancer — 按 cast 过滤 + 差异化对比

### 问题
voice section 注入全部角色（不按 cast 过滤），且仅列清单无对比指令。rewrite 路径丢弃所有模板变量。

### 方案
1. `buildCharacterVoiceSection(projectId, synopsis)` — 按 ChapterSynopsis.cast 过滤
2. `dialogueDifferentiation` 参数控制对比模式：
   - `"contrast"` (默认)：自动生成配对对比提示
   - `"individual"`：只列个体风格
   - `"none"`：不注入
3. rewriteForCorrection 传全部模板变量

### 修改文件

| 文件 | 改动 |
|------|------|
| `WritingPreferences.java` | +`dialogueDifferentiation` 字段 |
| `ContextAssembler.java` | buildCharacterVoiceSection 按 cast 过滤 + 对比生成 |
| `ChapterWriterAgent.java` | rewriteForCorrection 传全部变量 + sanitizeChapterNumbers |
| `preferences-chat.st` | 文档化 dialogueDifferentiation |

## p6-4: StyleProfileDynamicUpdate — 动态基线 + 漂移修正

### 问题
StyleProfile 构思时建立后从不更新。风格漂移 ContinuityIssue 只存不读。

### 方案
1. 卷末用 StyleGuardianAgent 从最近 5 章重新评估，**合并**到 StyleProfile
2. buildStyleSection 注入最近风格漂移修正指令

### 修改文件

| 文件 | 改动 |
|------|------|
| `NovelOrchestrator.java` | generateVolumeSummary 中追加 StyleProfile 更新 |
| `StyleGuardianAgent.java` | +`updateProfile(projectId, recentChapters)` |
| `ContextAssembler.java` | buildStyleSection 注入漂移修正 |
