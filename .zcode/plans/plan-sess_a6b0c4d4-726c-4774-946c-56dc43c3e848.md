# 前端搭建方案：React + Vite（打包进 Spring Boot）

## 架构决策

- **技术栈**：React 18 + Vite + TypeScript（UI 库用 Ant Design 5，表格/表单/布局开箱即用）
- **跨域**：前端打包到 Spring Boot `src/main/resources/static/`，同源访问（生产零 CORS 问题）。开发时用 Vite proxy 转发 `/api` 到 `localhost:8080`
- **API 客户端**：手写 `api.ts`（fetch 封装），不引入重型状态管理库——用 React Context + hooks 管理项目状态即可
- **后端微调**：加一个全局异常处理器（`@RestControllerAdvice`）把 `IllegalArgumentException` 等转成 400 JSON，加一个简单的 `WebMvcConfigurer` 允许开发时 CORS（可选，主要靠 proxy）

## 页面结构（4 个视图）

```
App (Layout: 侧边栏 + 内容区)
├── ProjectListPage      项目列表 + 创建表单
├── ProjectWorkspace     项目工作台（选中项目后）
│   ├── RunConsole           运行控制台（状态机 + 运行/写章节 + 模式切换）
│   ├── WorldbuildingView    世界观条目（按类型分组）+ 人物卡

```

## 实施计划（分 Task）

### Task 1：后端微调（全局异常处理）
- 创建 `GlobalExceptionHandler`：`IllegalArgumentException` → 400 JSON `{error: msg}`
- 确保 `static/` 资源能被正确服务（Spring Boot 默认已支持）

### Task 2：前端骨架
- 初始化 Vite + React + TS 项目（`frontend/` 目录）
- 安装 antd
- 配置 `vite.config.ts`（proxy `/api` → 8080，build output 指向 `../src/main/resources/static/`）
- `api/client.ts`：封装全部 16 个端点
- `types.ts`：TS 类型定义

### Task 3：项目列表页 + 创建表单
- `ProjectListPage`：表格展示所有项目（标题/状态/模式/进度）+ 创建对话框
- 创建表单：标题、构思、标签、模式（Solo/交互）
- 点击项目 → 进入工作台

### Task 4：项目工作台 + 运行控制台
- `ProjectWorkspace`：Layout（侧边项目信息 + 内容 Tab）
- `RunConsole`：状态机指示器（当前状态高亮）+ 模式切换 + "推进"按钮（POST /run）+ "写一章"按钮（POST /write-chapter）
- 两个慢操作都要 loading 状态 + 结果反馈

### Task 5：世界观/人物/大纲/阅读器
- `WorldbuildingView`：知识条目按 type 分组展示 + 人物卡列表（角色/性格/能力）
- `OutlineView`：树形展示 总纲→卷→章节梗概
- `ChapterReader`：章节列表 + 正文阅读（支持翻页）

### Task 6：打包进后端 + 端到端验证
- `npm run build` → 输出到 `src/main/resources/static/`
- 启动 Spring Boot，浏览器访问 `localhost:8080` 验证全链路
- 创建项目 → 运行构思 → 查看世界观/人物/大纲 → 写一章 → 阅读

## 关键设计点

1. **慢操作处理**：`/run` 和 `/write-chapter` 调 LLM 可能 30-60 秒。前端用 loading spinner + 禁用按钮，超时设 5 分钟
2. **状态轮询**：运行后刷新 `/status` 更新状态机指示器
3. **null 安全**：`/outline` 和 `/chapters/{idx}` 可能返回 null，前端做空判断
4. **`PUT /mode` 特殊 body**：发送裸 JSON 字符串 `"INTERACTIVE"`，不是对象
