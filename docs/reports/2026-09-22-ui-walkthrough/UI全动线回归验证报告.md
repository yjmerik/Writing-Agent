## 本轮发现

- **F4（P2，登记）同步检查占坑不可取消**：补查/推进类同步操作以匿名 workId 占用项目工作权，
  期间无进度展示、不可取消；LLM 调用挂起时占坑持续到超时（实测一次 20 分钟后重试耗尽）。
  NCS-072 的任务终止只覆盖任务型占坑，对匿名 workId 无效；作者只能等超时或重启实例。
- **F5（P2，登记）worker 收尾窗口批准 409 无等待提示**：每章审阅下检查点在 worker 仍在跑
  质量检查时即出现，此时批准会 409（"已有进行中的写作任务"），错误未提示"Agent 正在收尾，
  稍候再试"；本轮第 1、2 章批准各遇到一次，等待后重试即成功。
- **F3 二次实证（已有登记）**：补查成功后章节仍为 NEEDS_MANUAL_REVIEW，解除屏障所需的
  resolve-review（人工复核确认）在前端无入口——作者无法从界面完成"确认已复核"。与 F1 中
  裁决 UI 缺失同根：后端能力齐备、前端入口缺失。
