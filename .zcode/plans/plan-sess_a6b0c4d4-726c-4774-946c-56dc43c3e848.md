# 长程一致性 + 情节质量提升方案

## 问题根因

### 长程一致性（当前 6/10 → 目标 8+）
1. **Agent 间名字不一致**：`runConceiving` 的调用顺序是世界→风格→人物→大纲。Plotter 独立调用 LLM 生成大纲，不知道 CharacterDesigner 给主角取了什么名字，导致大纲总纲用"陆沉"而人物卡用"白折"。
2. **章节标题错乱**：ChapterWriter 收到的章节梗概只有 `synopsis` 文本，没有显式要求章节标题必须与大纲一致。

### 情节质量（当前 6/10 → 目标 8+）
1. **大纲节奏急躁**：Plotter 的 prompt 缺乏节奏控制，LLM 倾向于"10 章走完全书"的快进模式。
2. **每章梗概简陋**：现在的梗概是一句话描述，没有场景节拍、爽点、冲突设计。
3. **叙事套路化**：缺乏基于世界观独特设定的创新引导。

## 修复方案（4 个改动点）

### Fix 1：Agent 间主角名传递（长程一致性核心）

**改动 `NovelOrchestrator.runConceiving`**：
- 人物生成后，提取主角姓名
- 将主角名传给 `plotter.plan` 的 theme 参数（如 "主角名为「白折」，主题：..."）
- Plotter 在原 prompt 的用户消息中收到主角名约束

```java
// 人物设计后提取主角名
String protagonistName = "";
var chars = repository.findCharactersByProject(projectId);
for (var c : chars) {
    if (c.getRole() != null && c.getRole().contains("主角")) {
        protagonistName = c.getName();
        break;
    }
}

// 传给 Plotter
String plotTheme = (protagonistName.isEmpty() ? "" : "主角名为「" + protagonistName + "」。")
        + "主题：" + p.getConcept();
plotter.plan(projectId, p.getConcept(), plotTheme, 10);
```

**改动 `PlotterAgent.plan` 的 userMessage**：
- 增加主角名注入到 prompt 顶部

### Fix 2：大纲节奏控制（情节质量）

**改动 `plotting.st` 模板**：
- 增加节奏要求："成长要循序渐进。每卷主角只完成一个阶段的成长，不能跳跃式升级。"
- 增加每章结构要求："每章的「场景节拍」必须包含 3-5 个具体场景（如：被嘲笑→遭遇危机→觉醒反击→众人震惊），不能是笼统的概述。"
- 增加总卷数约束（通过 userMessage template 参数控制）

### Fix 3：章节标题一致性（长程一致性）

**改动 `ChapterWriterAgent.write`**：
- 在 userPrompt 的开头锚定声明中加入章节标题信息
- 在 `chapter-writing.st` 中增加"章节标题必须与【本章任务】中的标题完全一致"

### Fix 4：章节结构约束（情节质量）

**改动 `chapter-writing.st` 模板**：
- 增加"每章结构"要求：`开场钩子（吸引读者）→ 冲突升级 → 高潮/爽点 → 悬念结尾（让读者想看下一章）`
- 这不需要改代码，只需要改模板文件

## 实施顺序

1. Fix 1（主角名传递）→ 解决 Agent 间一致性问题
2. Fix 2（大纲节奏控制）→ 提升情节质量
3. Fix 3（章节标题一致性）→ 消除章节序号错乱
4. Fix 4（章节结构约束）→ 进一步提升单章质量

## 验证方式

新建项目，写 3-5 章，跑质量评价。重点验证：
- 大纲总纲的主角名是否与人物卡一致（Fix 1）
- 正文章节标题是否与大纲一致（Fix 3）
- 大纲节奏是否合理（Fix 2）
