# 质量全面提升方案：PromptTemplate 系统 + 5 维度优化

## 目标
- 5 个质量维度（一致性/风格/情节/人物/世界观）全部提升到 8/10+
- 统一 Prompt 抽象层，prompt 外置可调优，支持按模型差异化

## 架构：PromptTemplate 系统

```
src/main/resources/prompts/           # prompt 模板目录（可不改代码调优）
├── worldbuilding.st                  # WorldBuilder 的 system prompt
├── character-design.st               # CharacterDesigner
├── plotting.st                       # Plotter
├── chapter-writing.st                # ChapterWriter
├── chapter-writing-user.st           # ChapterWriter 的 user prompt 头部
├── continuity-check.st               # ContinuityChecker
├── style-establish.st                # StyleGuardian 建立基线
├── style-check.st                    # StyleGuardian 检查一致性
├── memory-summary.st                 # MemoryManager
└── quality-evaluate.st               # QualityEvaluationAgent
```

新建 `PromptTemplateService`：
- 启动时加载 `prompts/*.st` 文件到内存
- `render(templateName, variables)` 方法支持 `{{var}}` 变量插值
- 支持 `{{#if var}}...{{/if}}` 条件块
- Agent 调 `promptService.render("chapter-writing", Map.of("concept", ..., "tags", ...))` 取代硬编码

ModelConfig 增加可选 `styleGuide` 字段：
```yaml
llm:
  models:
    CHAPTER_WRITING:
      model: glm-5.2
      style-guide: "纯古典仙侠风格。禁止出现机械、科幻、数据流、义眼等元素。所有技术描写必须用修仙术语。"
```
Gateway 在 systemPrompt 末尾自动拼接 `style-guide`（若配置了）。

## 5 个维度的优化（对应 5 个 Task）

### Task 1：PromptTemplate 系统 + 改造全部 Agent
**新建：**
- `src/main/java/com/writing/novel/llm/prompt/PromptTemplateService.java` — 模板加载+渲染
- `src/main/java/com/writing/novel/llm/prompt/PromptTemplateConfig.java` — Spring 装配
- `src/main/resources/prompts/*.st` — 10 个模板文件

**改造：** 7 个 Agent 从硬编码 prompt 改为 `promptService.render(...)`，同时 ModelConfig 加 `styleGuide` 字段、Gateway 自动拼接。

### Task 2：增强大纲生成（情节质量 5→8）
**改造 PlotterAgent + plotting.st：**
- 每章梗概从 1 句话扩展为结构化：`【节拍】3-5个场景推进 + 【爽点】本章核心爽感 + 【人物出场】 + 【伏笔】`
- 新增 `ChapterSynopsis` 的写作指引更丰富
- prompt 中要求避免套路化，基于世界观独特设定设计创新爽点

### Task 3：风格基线前置（风格统一 6→8）
**改造 NovelOrchestrator.runConceiving：**
- 构思阶段新增第 0 步：WorldBuilder 生成世界观后，**立即用 StyleGuardian 建立风格基线**（基于世界观+构思生成 tone/voice/dosAndDonts）
- 之后 CharacterDesigner 和 Plotter 都能看到风格基线
- ChapterWriter 通过 ContextAssembler 注入风格（已有，但之前 StyleProfile 为空）

### Task 4：人设自洽校验（人物塑造 6→8）
**改造 character-design.st + CharacterDesignerAgent：**
- prompt 增加"背景自洽性约束"：要求性格/外貌/能力/背景之间不矛盾
- 显式要求：如果角色定位是"废柴"，外貌/背景必须匹配（不能又是贵族又是底层杂役）
- 增加"人设独特性"要求：避免千篇一律的"慵懒毒舌"模板

### Task 5：写作约束强化（一致性+世界观 4/7→8+）
**改造 chapter-writing.st + ContextAssembler：**
- systemPrompt 增加"类型边界"约束：基于 tags 推断类型（玄幻→禁止科幻元素），明确列出禁止出现的元素
- 章节标题统一格式约束：正文内必须使用与大纲一致的标题格式
- 强化人物锚定（已有"不得改名"，再加"性格必须与人物卡一致，不得突变"）
- 新增"前文衔接"显式指令：要求开头自然承接上一章结尾

## 实施顺序
Task 1（PromptTemplate 系统）是地基，必须先做。Task 2-5 都依赖它（改 prompt 变成改模板文件）。然后按维度独立性并行实施。

## 验证方式
新建 3 章小项目，生成后跑质量评价，对比 5 个维度评分是否都达到 8+。
